This program simulates students going through the primary flight school syllabus. 
Toggle between different class-up sizes and syllabus types.
Run with: python3 simulation.py
Step through each day by running: python3 viewer.py

*Note: You must run simulation.py before running viewer.py
If you want to run simulation.py on a different combination of the parameters 
and then want to run viewer.py, be sure to first delete the "outputs" directory.
You can do so by typing the following into the terminal: rm -r outputs
